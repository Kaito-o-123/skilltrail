# 学習ロードマップ・スキル成長管理アプリ 画面設計書

## 1. 目的

本設計書では、SkillTrailの現行実装に存在する画面について、URL、目的、表示項目、入力項目、操作、遷移先を整理する。テンプレートおよびViewの実装内容と一致する画面仕様を定義する。

## 3. 共通レイアウト

### 3.1 サイドバー

全画面で共通表示し、次のメニューを提供する。

- SkillTrailロゴ・アプリケーション名
- ダッシュボード
- 学習目標
- タスク
- 振り返り
- 状態を示す凡例

現在表示している機能に応じて対象メニューをアクティブ表示する。

### 3.2 メッセージ表示

Django Messages Frameworkにメッセージが存在する場合、メインコンテンツ上部に表示する。

主なメッセージ：

- `登録しました。`
- `更新しました。`
- `削除しました。`
- `タスクを完了にしました。`
- `入力内容を確認してください。`

### 3.3 CSRF対策

登録・更新・削除・完了等のPOSTフォームにはCSRFトークンを設定する。

## 4. ダッシュボード画面

### 4.1 URL

`GET /`

### 4.2 目的

アプリ起動後に現在の学習状況を一画面で把握する。

### 4.3 表示項目

| エリア | 表示内容 |
|---|---|
| サマリー | 学習中目標数、完了済み目標数、未完了タスク数、今月の学習時間 |
| 学習目標ごとの進捗 | 完了済み以外の学習目標、ステータス、進捗率、進捗ゲージ |
| 期限が近いタスク | タスク名、学習目標名、優先度、期限。最大6件 |
| 最近の振り返り | 学習日、学習目標、学んだこと。最大3件 |

### 4.4 操作

| 操作 | 遷移先 |
|---|---|
| 新規目標登録 | 学習目標登録 |
| 学習目標を選択 | 学習目標詳細 |
| 「すべて見る」 | 学習目標一覧 |
| 最近の振り返り「登録」 | 振り返り登録 |

## 5. 学習目標一覧画面

### 5.1 URL

`GET /goals/`

### 5.2 表示・検索条件

| 項目 | 仕様 |
|---|---|
| キーワード | タイトル・目的を部分一致検索 |
| カテゴリ | 登録済みカテゴリから選択 |
| ステータス | 未着手、学習中、完了、中断から選択 |
| 条件クリア | 検索条件なしの一覧へ戻る |

※期限による絞り込みは現行画面に存在しない。

### 5.3 一覧表示

各学習目標について、実装テンプレート上のタイトル、カテゴリ、ステータス、日付、進捗等を表示し、詳細・編集・削除等の操作へ遷移する。

### 5.4 操作

- 新規登録
- 詳細表示
- 編集
- 削除
- 検索・絞り込み
- 条件クリア

## 6. 学習目標詳細画面

### 6.1 URL

`GET /goals/<id>/`

### 6.2 基本情報エリア

- カテゴリ
- タイトル
- 目的
- メモ
- ステータス
- 開始日
- 目標期限
- 学習時間合計
- 進捗率
- 完了タスク数 / 全タスク数

未入力の目的・メモ・日付は画面上で `―` として表示する。

### 6.3 ロードマップエリア

学習目標に紐づくロードマップを `sort_order`, `id` 順に表示する。各ステップ配下に紐づくタスクを表示し、ステップ追加・編集・削除・上下移動、タスク追加等の操作を提供する。

### 6.4 振り返りエリア

対象学習目標に紐づく振り返りを表示し、登録・編集・削除へ遷移できる。

### 6.5 操作

- 学習目標一覧へ戻る
- 学習目標編集
- 学習目標削除
- ロードマップステップ追加・編集・削除・並び順変更
- タスク登録・編集・削除・完了
- 振り返り登録・編集・削除

## 7. 学習目標登録・編集画面

### 7.1 URL

- 登録：`GET/POST /goals/new/`
- 編集：`GET/POST /goals/<id>/edit/`

### 7.2 入力項目

| 項目 | UI | 必須 | 制約 |
|---|---|---|---|
| タイトル | テキスト | ○ | 最大200文字 |
| カテゴリ | セレクト | ○ | Categoryから選択 |
| 目的 | テキストエリア | - | 任意 |
| 開始日 | 日付 | - | 日付形式 |
| 目標期限 | 日付 | - | 開始日以降 |
| ステータス | セレクト | ○ | 定義済み4値 |
| メモ | テキストエリア | - | 任意 |

### 7.3 正常時遷移

- 登録成功：学習目標一覧
- 編集成功：学習目標詳細

### 7.4 入力エラー時

同一フォームを入力値・フィールドエラー付きで再表示し、共通エラーメッセージを表示する。

## 8. 学習目標削除確認画面

### 8.1 URL

`GET/POST /goals/<id>/delete/`

### 8.2 表示内容

- 削除対象名
- 「紐づくロードマップ・タスク・振り返りもすべて削除されます。」の警告
- 操作が取り消せない旨

### 8.3 操作

- キャンセル：学習目標詳細へ戻る
- 削除する：POSTで削除し、学習目標一覧へ遷移

## 9. ロードマップ登録・編集画面

### 9.1 URL

- 登録：`GET/POST /goals/<goal_id>/roadmaps/new/`
- 編集：`GET/POST /roadmaps/<id>/edit/`

### 9.2 入力項目

| 項目 | UI | 必須 | 制約 |
|---|---|---|---|
| ステップ名 | テキスト | ○ | 最大200文字 |
| 説明 | テキストエリア | - | 任意 |
| 並び順 | 数値 | ○ | 1以上 |
| ステータス | セレクト | ○ | 未着手、進行中、完了 |

新規登録時、並び順には既存ステップ数+1を初期表示する。

### 9.3 正常時遷移

登録・編集とも対象学習目標の詳細画面へ戻る。

## 10. ロードマップ削除確認画面

`GET/POST /roadmaps/<id>/delete/`

- 紐づくタスクも削除される旨を警告する。
- キャンセル時は学習目標詳細へ戻る。
- 削除確定後も学習目標詳細へ戻る。

## 11. ロードマップ並び順変更

専用画面は持たない。

- URL：`/roadmaps/<id>/move/up/` または `/roadmaps/<id>/move/down/`
- 処理後：対象学習目標詳細へリダイレクト
- 同一学習目標内の隣接ステップと並び順を交換する。

## 12. タスク一覧画面

### 12.1 URL

`GET /tasks/`

### 12.2 検索・絞り込み

| 項目 | 仕様 |
|---|---|
| キーワード | タスク名・メモを部分一致検索 |
| 学習目標 | 学習目標単位で絞り込み |
| ステータス | 未着手、進行中、完了 |
| 優先度 | 高、中、低 |

※期限を直接指定する検索UIは現行実装にはない。

### 12.3 一覧表示

- タスク名
- 学習目標名・ロードマップ名
- ステータス
- 優先度
- 期限
- 教材URLリンク（登録時のみ）
- 編集・削除ボタン
- 完了ボタン

期限超過タスクは期限表示を強調する。完了済みタスクでは完了ボタンを無効化する。

### 12.4 操作

- 新規登録
- 編集
- 削除
- 完了
- 検索・絞り込み
- 条件クリア

## 13. タスク登録・編集画面

### 13.1 URL

- 登録：`GET/POST /tasks/new/`
- 編集：`GET/POST /tasks/<id>/edit/`

### 13.2 入力項目

| 項目 | UI | 必須 | 制約 |
|---|---|---|---|
| 学習目標 | セレクト | ○ | LearningGoalから選択 |
| ロードマップ | セレクト | ○ | 選択した学習目標に属するもの |
| タスク名 | テキスト | ○ | 最大200文字 |
| 教材URL | URL | - | URL形式、最大500文字 |
| 優先度 | セレクト | ○ | 高、中、低 |
| 期限 | 日付 | - | 日付形式 |
| ステータス | セレクト | ○ | 未着手、進行中、完了 |
| メモ | テキストエリア | - | 任意 |

### 13.3 学習目標・ロードマップ連動

JavaScriptにより学習目標の選択に応じてロードマップ選択肢を絞り込む。さらにサーバー側Formでも両者の所属関係を検証する。

### 13.4 戻り先制御

`next` が指定されている場合、登録・編集完了およびキャンセル時にそのURLへ戻る。未指定時はタスク一覧へ戻る。

## 14. タスク削除確認画面

`GET/POST /tasks/<id>/delete/`

- 削除対象タスク名を表示する。
- `next` が指定されている場合はキャンセル・削除後とも呼び出し元へ戻る。
- 未指定の場合はタスク一覧を既定とする。

## 15. タスク完了処理

専用画面は持たない。

- URL：`POST /tasks/<id>/complete/`
- `status` を `completed` に更新する。
- 完了メッセージを表示する。
- `next` 指定先、またはタスク一覧へリダイレクトする。

## 16. 振り返り一覧画面

### 16.1 URL

`GET /reflections/`

### 16.2 絞り込み

学習目標による絞り込みのみ提供する。

### 16.3 表示項目

- 学習日
- 学習目標
- 学習時間
- 学んだこと
- 詰まったこと（入力時のみ）
- 次にやること（入力時のみ）
- 編集・削除操作

## 17. 振り返り登録・編集画面

### 17.1 URL

- 登録：`GET/POST /reflections/new/`
- 編集：`GET/POST /reflections/<id>/edit/`

### 17.2 入力項目

| 項目 | UI | 必須 | 制約 |
|---|---|---|---|
| 学習目標 | セレクト | ○ | LearningGoalから選択 |
| 学習日 | 日付 | ○ | 新規時は当日を初期値 |
| 学習時間（分） | 数値 | - | 0以上の整数 |
| 学んだこと | テキストエリア | ○ | 任意長テキスト |
| 詰まったこと | テキストエリア | - | 任意 |
| 次にやること | テキストエリア | - | 任意 |

### 17.3 戻り先制御

`next` が指定されている場合は完了・キャンセル時に指定先へ戻り、未指定の場合は振り返り一覧へ戻る。

## 18. 振り返り削除確認画面

`GET/POST /reflections/<id>/delete/`

- 削除対象を表示する。
- キャンセルまたは削除後は `next` 指定先、未指定時は振り返り一覧へ戻る。
