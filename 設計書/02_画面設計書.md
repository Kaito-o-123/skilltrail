# 学習ロードマップ・スキル成長管理アプリ 画面設計書

## 1. 目的

本設計書では、学習ロードマップ・スキル成長管理アプリで作成する画面を整理する。  
各画面の目的、表示項目、入力項目、操作内容、画面遷移を明確にする。

---

## 2. 画面一覧

| No | 画面名 | 概要 |
|---|---|---|
| 1 | ダッシュボード画面 | 学習状況を一覧表示する |
| 2 | 学習目標一覧画面 | 登録済みの学習目標を一覧表示する |
| 3 | 学習目標詳細画面 | 目標ごとのロードマップや進捗を表示する |
| 4 | 学習目標登録画面 | 新しい学習目標を登録する |
| 5 | 学習目標編集画面 | 登録済みの学習目標を編集する |
| 6 | ロードマップ管理画面 | 学習ステップを管理する |
| 7 | タスク一覧画面 | 学習タスクを一覧表示する |
| 8 | タスク登録画面 | 学習タスクを登録する |
| 9 | タスク編集画面 | 登録済みの学習タスクを編集する |
| 10 | 振り返り一覧画面 | 学習の振り返りを一覧表示する |
| 11 | 振り返り登録画面 | 学習内容を記録する |
| 12 | 振り返り編集画面 | 登録済みの振り返りを編集する |

---

## 3. 共通レイアウト

### 3.1 ヘッダー

表示内容：

- アプリケーション名
- ダッシュボードへのリンク
- 学習目標一覧へのリンク
- タスク一覧へのリンク
- 振り返り一覧へのリンク

### 3.2 メインエリア

画面ごとの内容を表示する。

### 3.3 メッセージ表示エリア

登録・更新・削除完了時やエラー発生時にメッセージを表示する。

表示例：

- 登録しました
- 更新しました
- 削除しました
- 入力内容を確認してください

---

## 4. ダッシュボード画面

### 4.1 目的

アプリ起動後に、現在の学習状況をすぐ確認できるようにする。

### 4.2 表示項目

| 項目 | 内容 |
|---|---|
| 学習中の目標数 | ステータスが学習中の目標数 |
| 完了済み目標数 | ステータスが完了の目標数 |
| 未完了タスク数 | 完了していないタスク数 |
| 期限が近いタスク | 期限日が近いタスク |
| 今月の学習時間 | 当月に登録した学習時間の合計 |
| 学習目標ごとの進捗率 | 各学習目標の進捗率 |
| 最近の振り返り | 直近で登録した振り返り |

### 4.3 操作内容

| 操作 | 内容 |
|---|---|
| 学習目標を選択 | 学習目標詳細画面へ遷移 |
| タスクを選択 | タスク編集画面へ遷移 |
| 新規目標登録 | 学習目標登録画面へ遷移 |
| 振り返り登録 | 振り返り登録画面へ遷移 |

---

## 5. 学習目標一覧画面

### 5.1 目的

登録済みの学習目標を一覧で確認する。

### 5.2 表示項目

| 項目 | 内容 |
|---|---|
| タイトル | 学習目標名 |
| カテゴリ | 学習分野 |
| ステータス | 未着手、学習中、完了、中断 |
| 開始日 | 学習開始日 |
| 目標期限 | 完了予定日 |
| 進捗率 | タスク完了状況から算出 |
| 更新日 | 最終更新日 |

### 5.3 検索・絞り込み項目

| 項目 | 内容 |
|---|---|
| キーワード | タイトルや目的を検索 |
| カテゴリ | 学習分野で絞り込み |
| ステータス | 状態で絞り込み |
| 期限 | 目標期限で絞り込み |

### 5.4 操作内容

| 操作 | 内容 |
|---|---|
| 詳細 | 学習目標詳細画面へ遷移 |
| 編集 | 学習目標編集画面へ遷移 |
| 削除 | 削除確認後、対象の学習目標を削除 |
| 新規登録 | 学習目標登録画面へ遷移 |

---

## 6. 学習目標詳細画面

### 6.1 目的

1つの学習目標に対するロードマップ、タスク、進捗、振り返りを確認する。

### 6.2 表示項目

| 項目 | 内容 |
|---|---|
| タイトル | 学習目標名 |
| カテゴリ | 学習分野 |
| 目的 | 学習目的 |
| 開始日 | 学習開始日 |
| 目標期限 | 完了予定日 |
| ステータス | 現在の状態 |
| 進捗率 | タスク完了状況から算出 |
| ロードマップ一覧 | 紐づく学習ステップ |
| 関連タスク一覧 | 紐づくタスク |
| 振り返り履歴 | 紐づく振り返り |
| 学習時間合計 | 登録された学習時間の合計 |

### 6.3 操作内容

| 操作 | 内容 |
|---|---|
| ロードマップ追加 | ロードマップ管理画面へ遷移 |
| タスク追加 | タスク登録画面へ遷移 |
| 振り返り追加 | 振り返り登録画面へ遷移 |
| 編集 | 学習目標編集画面へ遷移 |
| 一覧へ戻る | 学習目標一覧画面へ戻る |

---

## 7. 学習目標登録・編集画面

### 7.1 目的

学習目標の新規登録または編集を行う。

### 7.2 入力項目

| 項目 | 入力形式 | 必須 | 内容 |
|---|---|---|---|
| タイトル | テキスト | ○ | 学習目標名 |
| カテゴリ | セレクト | ○ | 学習分野 |
| 目的 | テキストエリア | - | 学習目的 |
| 開始日 | 日付 | - | 学習開始日 |
| 目標期限 | 日付 | - | 完了予定日 |
| ステータス | セレクト | ○ | 未着手、学習中、完了、中断 |
| メモ | テキストエリア | - | 補足情報 |

### 7.3 入力チェック

| 項目 | チェック内容 |
|---|---|
| タイトル | 必須 |
| カテゴリ | 必須 |
| 開始日 | 日付形式 |
| 目標期限 | 日付形式 |
| ステータス | 指定値のみ許可 |

### 7.4 操作内容

| 操作 | 内容 |
|---|---|
| 登録 | 入力内容をDBに保存 |
| 更新 | 変更内容をDBに保存 |
| キャンセル | 一覧画面または詳細画面へ戻る |

---

## 8. ロードマップ管理画面

### 8.1 目的

学習目標に紐づく学習ステップを管理する。

### 8.2 表示項目

| 項目 | 内容 |
|---|---|
| ステップ名 | 学習ステップ名 |
| 説明 | 学習内容の説明 |
| 並び順 | 学習順序 |
| ステータス | 未着手、進行中、完了 |
| 関連タスク数 | ステップに紐づくタスク数 |

### 8.3 入力項目

| 項目 | 入力形式 | 必須 | 内容 |
|---|---|---|---|
| ステップ名 | テキスト | ○ | 学習ステップ名 |
| 説明 | テキストエリア | - | 学習内容の説明 |
| 並び順 | 数値 | ○ | 学習順序 |
| ステータス | セレクト | ○ | 未着手、進行中、完了 |

### 8.4 操作内容

| 操作 | 内容 |
|---|---|
| ステップ追加 | 新しいステップを登録 |
| 編集 | ステップ内容を編集 |
| 削除 | ステップを削除 |
| 並び順変更 | 学習順序を変更 |
| ステータス更新 | 未着手、進行中、完了に変更 |
