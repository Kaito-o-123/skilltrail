# 学習ロードマップ・スキル成長管理アプリ 機能設計書

## 1. 目的

本設計書では、学習ロードマップ・スキル成長管理アプリに実装する機能を整理する。  
各機能の目的、概要、入力内容、出力内容、実装優先度を明確にし、後続の画面設計・DB設計・詳細設計につなげる。

---

## 2. アプリケーション概要

本アプリケーションは、学習したい技術やスキルを登録し、学習ロードマップ、学習タスク、進捗、振り返りを管理するWebアプリケーションである。

単なる学習記録ではなく、以下を一元管理できることを目的とする。

- 学習目標の管理
- 学習順序の整理
- 学習タスクの管理
- 進捗状況の可視化
- 学習内容の振り返り
- 今後の学習計画の整理

---

## 3. 機能一覧

| No | 機能名 | 概要 | 優先度 |
|---|---|---|---|
| 1 | 学習目標管理 | 学習したい技術やスキルを登録・編集・削除する | 高 |
| 2 | ロードマップ管理 | 学習目標に対して学習ステップを作成する | 高 |
| 3 | 学習タスク管理 | 各ステップに紐づくタスクを管理する | 高 |
| 4 | 進捗管理 | タスク完了状況をもとに進捗率を表示する | 高 |
| 5 | 振り返り管理 | 学習内容、詰まった点、次にやることを記録する | 中 |
| 6 | 検索・絞り込み | カテゴリ、ステータス、期限などで絞り込む | 中 |
| 7 | ダッシュボード表示 | 学習状況を一覧で可視化する | 中 |
| 8 | カテゴリ管理 | 学習テーマをカテゴリ別に管理する | 中 |
| 9 | 学習時間管理 | 学習時間を記録・集計する | 低 |
| 10 | 認証機能 | ログインユーザーごとにデータを管理する | 低〜中 |

---

## 4. 学習目標管理機能

### 4.1 概要

学習したい技術やスキルを学習目標として登録する機能。  
例として、Django、Python、React、AWS、資格学習などを管理対象とする。

### 4.2 主な操作

- 学習目標の新規登録
- 学習目標の一覧表示
- 学習目標の詳細表示
- 学習目標の編集
- 学習目標の削除
- 学習ステータスの更新

### 4.3 入力項目

| 項目 | 内容 |
|---|---|
| タイトル | 学習目標名 |
| カテゴリ | 学習分野 |
| 目的 | なぜ学習するのか |
| 開始日 | 学習開始日 |
| 目標期限 | 完了予定日 |
| ステータス | 未着手、学習中、完了、中断 |
| メモ | 補足情報 |

### 4.4 出力内容

- 学習目標一覧
- 学習目標詳細
- 学習目標ごとの進捗率
- 関連するロードマップ
- 関連するタスク
- 関連する振り返り

---

## 5. ロードマップ管理機能

### 5.1 概要

学習目標に対して、学習ステップを順番に登録する機能。  
学習の流れを見える化し、何から取り組むべきか分かるようにする。

### 5.2 主な操作

- ロードマップステップの登録
- ロードマップステップの編集
- ロードマップステップの削除
- 並び順の管理
- ステータス更新

### 5.3 入力項目

| 項目 | 内容 |
|---|---|
| 学習目標 | 紐づく学習目標 |
| ステップ名 | 学習ステップ名 |
| 説明 | 学習内容の説明 |
| 並び順 | 学習する順番 |
| ステータス | 未着手、進行中、完了 |
| メモ | 補足情報 |

### 5.4 出力内容

- 学習目標ごとのロードマップ
- ステップごとの進捗
- ステップに紐づくタスク一覧

---

## 6. 学習タスク管理機能

### 6.1 概要

ロードマップの各ステップに対して、具体的な学習タスクを登録する機能。  
教材URL、期限、優先度、ステータスを管理できるようにする。

### 6.2 主な操作

- タスクの登録
- タスクの編集
- タスクの削除
- タスクの完了
- 優先度の設定
- 期限の設定

### 6.3 入力項目

| 項目 | 内容 |
|---|---|
| ロードマップ | 紐づくロードマップ |
| タスク名 | 実施する学習タスク |
| 教材URL | 参考資料や教材のURL |
| 優先度 | 高、中、低 |
| 期限 | 完了予定日 |
| ステータス | 未着手、進行中、完了 |
| メモ | 補足情報 |

### 6.4 出力内容

- タスク一覧
- 未完了タスク
- 完了済みタスク
- 期限が近いタスク
- 学習目標ごとのタスク進捗

---

## 7. 進捗管理機能

### 7.1 概要

タスクやロードマップの完了状況をもとに、学習目標ごとの進捗率を表示する機能。

### 7.2 主な操作

- タスク完了状況の集計
- 学習目標ごとの進捗率表示
- ロードマップごとの進捗率表示
- ダッシュボードへの反映

### 7.3 進捗率の考え方

進捗率 = 完了タスク数 / 全タスク数 × 100

### 7.4 出力内容

* 学習目標ごとの進捗率
* 完了タスク数
* 未完了タスク数
* 全体の学習進捗

---

## 8. 振り返り管理機能

### 8.1 概要

日々の学習内容、詰まった点、次にやることを記録する機能。

### 8.2 主な操作

* 振り返りの登録
* 振り返りの一覧表示
* 振り返りの編集
* 振り返りの削除

### 8.3 入力項目

| 項目     | 内容       |
| ------ | -------- |
| 学習目標   | 紐づく学習目標  |
| 学習日    | 学習した日    |
| 学習時間   | 学習に使った時間 |
| 学んだこと  | 学習内容     |
| 詰まったこと | 課題や不明点   |
| 次にやること | 次回の予定    |

### 8.4 出力内容

* 振り返り一覧
* 学習目標ごとの振り返り履歴
* 学習時間の合計
* 過去の課題やメモ

---

## 9. 検索・絞り込み機能

### 9.1 概要

登録した学習目標、タスク、振り返りを条件指定して検索できるようにする。

### 9.2 検索条件

* キーワード
* カテゴリ
* ステータス
* 優先度
* 期限
* 学習日

### 9.3 出力内容

* 条件に一致した学習目標
* 条件に一致したタスク
* 条件に一致した振り返り

---

## 10. ダッシュボード表示機能

### 10.1 概要

学習状況を一覧で確認できるトップ画面を作成する。

### 10.2 表示内容

* 学習中の目標数
* 完了済み目標数
* 未完了タスク数
* 期限が近いタスク
* 今月の学習時間
* 学習目標ごとの進捗率
* 最近の振り返り

---

## 11. 実装対象範囲

初期実装では、以下を優先して実装する。

* 学習目標管理
* ロードマップ管理
* 学習タスク管理
* 進捗管理
* 振り返り管理
* ダッシュボード表示

認証機能や高度なグラフ表示は、基本機能の実装後に追加検討する。
