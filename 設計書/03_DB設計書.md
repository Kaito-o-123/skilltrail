# 学習ロードマップ・スキル成長管理アプリ DB設計書

## 1. 目的

本設計書では、学習ロードマップ・スキル成長管理アプリで利用するデータベース構成を整理する。  
テーブル、カラム、データ型、主キー、外部キー、リレーション、ステータス値を明確にする。

---

## 2. テーブル一覧

| テーブル名 | 概要 |
|---|---|
| users | ユーザー情報を管理する |
| categories | 学習カテゴリを管理する |
| learning_goals | 学習目標を管理する |
| roadmaps | 学習ステップを管理する |
| learning_tasks | 学習タスクを管理する |
| reflections | 学習の振り返りを管理する |

## 9. リレーション

| 親テーブル | 子テーブル | 関係 | 内容 |
|---|---|---|---|
| users | learning_goals | 1対多 | 1ユーザーが複数の学習目標を持つ |
| categories | learning_goals | 1対多 | 1カテゴリに複数の学習目標が紐づく |
| learning_goals | roadmaps | 1対多 | 1つの学習目標に複数のステップが紐づく |
| roadmaps | learning_tasks | 1対多 | 1つのステップに複数のタスクが紐づく |
| learning_goals | reflections | 1対多 | 1つの学習目標に複数の振り返りが紐づく |

---

## 10. 削除時の考慮

| 削除対象 | 影響 |
|---|---|
| learning_goals | 紐づくroadmaps、learning_tasks、reflectionsも削除対象 |
| roadmaps | 紐づくlearning_tasksも削除対象 |
| categories | 紐づくlearning_goalsがある場合は削除不可、または未分類へ変更 |
| users | 紐づく学習データも削除対象 |
