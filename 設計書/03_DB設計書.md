# 学習ロードマップ・スキル成長管理アプリ DB設計書

## 1. 目的

本設計書では、SkillTrailで利用するデータモデルを現行Django Modelおよび初期Migrationに基づいて定義する。テーブル相当のモデル、項目、型、必須性、既定値、外部キー、削除制約、並び順、およびDBへ保存しない派生値を明確にする。

## 2. DB・ORM方針

- Django ORMを利用してDBへアクセスする。
- 現行開発環境ではSQLiteを利用する。
- Django Model名に応じた実テーブル名は、`db_table` を明示していないためDjango既定の名称となる（例：`roadmap_learninggoal`）。
- 本設計書では可読性のため、モデル名と論理テーブル名を併記する。

## 3. モデル一覧

| Model | 論理名 | Django既定テーブル名 | 概要 |
|---|---|---|---|
| User | ユーザー | Django認証標準テーブル | 認証ユーザー |
| Category | カテゴリ | `roadmap_category` | 学習カテゴリ |
| LearningGoal | 学習目標 | `roadmap_learninggoal` | 学習目標 |
| Roadmap | ロードマップ | `roadmap_roadmap` | 学習ステップ |
| LearningTask | 学習タスク | `roadmap_learningtask` | ロードマップ配下のタスク |
| Reflection | 振り返り | `roadmap_reflection` | 日々の学習記録 |

## 4. User

Django標準の `AUTH_USER_MODEL` を利用する。SkillTrail独自のUserモデルは定義しない。

現行初期実装では認証を必須としておらず、`LearningGoal.user` はNULLを許可する。ログイン済みユーザーが学習目標を登録した場合のみ、そのユーザーを保存する。

## 5. Category（カテゴリ）

### 5.1 項目定義

| 項目 | Django型 | DB上の概念型 | 必須 | 既定値 | 制約・内容 |
|---|---|---|---|---|---|
| id | BigAutoField | bigint | ○ | 自動採番 | PK |
| name | CharField(100) | varchar(100) | ○ | - | カテゴリ名、UNIQUE |
| description | TextField | text | - | 空文字 | 説明 |
| created_at | DateTimeField | datetime | ○ | 自動 | 作成時刻を自動設定 |
| updated_at | DateTimeField | datetime | ○ | 自動 | 更新時刻を自動更新 |

### 5.2 並び順

`name` 昇順。

### 5.3 関連

`LearningGoal.category` から参照される。学習目標が存在するカテゴリは `PROTECT` により削除不可。

## 6. LearningGoal（学習目標）

### 6.1 項目定義

| 項目 | Django型 | DB上の概念型 | 必須 | 既定値 | 制約・内容 |
|---|---|---|---|---|---|
| id | BigAutoField | bigint | ○ | 自動採番 | PK |
| user_id | ForeignKey(User) | bigint | - | NULL | FK。初期実装ではNULL許可 |
| category_id | ForeignKey(Category) | bigint | ○ | - | FK、カテゴリ削除時PROTECT |
| title | CharField(200) | varchar(200) | ○ | - | 学習目標名 |
| purpose | TextField | text | - | 空文字 | 学習目的 |
| start_date | DateField | date | - | NULL | 開始日 |
| target_date | DateField | date | - | NULL | 目標期限 |
| status | CharField(20) | varchar(20) | ○ | `not_started` | 定義済みステータス |
| memo | TextField | text | - | 空文字 | メモ |
| created_at | DateTimeField | datetime | ○ | 自動 | 作成日時 |
| updated_at | DateTimeField | datetime | ○ | 自動 | 更新日時 |

### 6.2 status値

| 値 | 表示名 | 内容 |
|---|---|---|
| `not_started` | 未着手 | 学習開始前 |
| `in_progress` | 学習中 | 学習中 |
| `completed` | 完了 | 学習完了 |
| `suspended` | 中断 | 学習中断 |

### 6.3 並び順

Model既定順は `created_at` 降順。

### 6.4 削除ルール

- User削除時：`CASCADE` により対象ユーザーに紐づく学習目標も削除される。
- Category削除時：`PROTECT` により学習目標が存在するカテゴリは削除できない。
- LearningGoal削除時：RoadmapおよびReflectionがCASCADEで削除され、Roadmap削除に伴いLearningTaskも削除される。

### 6.5 DBへ保存しない派生値

| プロパティ | 内容 |
|---|---|
| `tasks` | ロードマップ経由で紐づく全LearningTask |
| `total_task_count` | 全タスク件数 |
| `completed_task_count` | `status=completed` のタスク件数 |
| `progress_rate` | 完了件数÷全件数×100をround。0件時0 |
| `total_study_minutes` | 紐づくReflectionのstudy_time合計。NULL合計時0 |

これらはDBカラムではなく、参照時に計算する。

## 7. Roadmap（ロードマップステップ）

### 7.1 項目定義

| 項目 | Django型 | DB上の概念型 | 必須 | 既定値 | 制約・内容 |
|---|---|---|---|---|---|
| id | BigAutoField | bigint | ○ | 自動採番 | PK |
| learning_goal_id | ForeignKey(LearningGoal) | bigint | ○ | - | FK、削除時CASCADE |
| title | CharField(200) | varchar(200) | ○ | - | ステップ名 |
| description | TextField | text | - | 空文字 | 説明 |
| sort_order | PositiveIntegerField | integer | ○ | 1 | 並び順。Formでは1以上を保証 |
| status | CharField(20) | varchar(20) | ○ | `not_started` | ステータス |
| created_at | DateTimeField | datetime | ○ | 自動 | 作成日時 |
| updated_at | DateTimeField | datetime | ○ | 自動 | 更新日時 |

### 7.2 status値

| 値 | 表示名 |
|---|---|
| `not_started` | 未着手 |
| `in_progress` | 進行中 |
| `completed` | 完了 |

### 7.3 並び順

`sort_order` 昇順、同値の場合 `id` 昇順。

### 7.4 削除ルール

LearningGoal削除時はCASCADE。Roadmap削除時は紐づくLearningTaskもCASCADE。

### 7.5 派生値

`task_count` は関連するタスク件数を返すプロパティで、DBには保存しない。

### 7.6 並び順に関する注意

DB上に `learning_goal_id + sort_order` のUNIQUE制約は設定していない。そのため同一目標内で同じ `sort_order` を持つレコードはDB上許容される。表示順は同値時に `id` で安定化する。

## 8. LearningTask（学習タスク）

### 8.1 項目定義

| 項目 | Django型 | DB上の概念型 | 必須 | 既定値 | 制約・内容 |
|---|---|---|---|---|---|
| id | BigAutoField | bigint | ○ | 自動採番 | PK |
| roadmap_id | ForeignKey(Roadmap) | bigint | ○ | - | FK、削除時CASCADE |
| title | CharField(200) | varchar(200) | ○ | - | タスク名 |
| material_url | URLField(500) | varchar(500) | - | 空文字 | 教材URL |
| priority | CharField(10) | varchar(10) | ○ | `medium` | 優先度 |
| due_date | DateField | date | - | NULL | 期限 |
| status | CharField(20) | varchar(20) | ○ | `not_started` | ステータス |
| memo | TextField | text | - | 空文字 | メモ |
| created_at | DateTimeField | datetime | ○ | 自動 | 作成日時 |
| updated_at | DateTimeField | datetime | ○ | 自動 | 更新日時 |

### 8.2 priority値

| 値 | 表示名 |
|---|---|
| `high` | 高 |
| `medium` | 中 |
| `low` | 低 |

### 8.3 status値

| 値 | 表示名 |
|---|---|
| `not_started` | 未着手 |
| `in_progress` | 進行中 |
| `completed` | 完了 |

### 8.4 並び順

`due_date` 昇順、同値の場合 `id` 昇順。期限未設定値の位置は利用DBのNULLソート規則に依存する。

### 8.5 関連・派生値

- 学習目標は直接FKとして保持せず、`roadmap.learning_goal` 経由で参照する。
- `learning_goal` プロパティはロードマップ経由で学習目標を返す。
- `is_overdue` は、期限あり・未完了・期限が当日より前の場合にTrueを返す。DBには保存しない。

## 9. Reflection（振り返り）

### 9.1 項目定義

| 項目 | Django型 | DB上の概念型 | 必須 | 既定値 | 制約・内容 |
|---|---|---|---|---|---|
| id | BigAutoField | bigint | ○ | 自動採番 | PK |
| learning_goal_id | ForeignKey(LearningGoal) | bigint | ○ | - | FK、削除時CASCADE |
| study_date | DateField | date | ○ | - | 学習日 |
| study_time | PositiveIntegerField | integer | - | NULL | 学習時間（分）、非負整数 |
| learned | TextField | text | ○ | - | 学んだこと |
| problem | TextField | text | - | 空文字 | 詰まったこと |
| next_action | TextField | text | - | 空文字 | 次にやること |
| created_at | DateTimeField | datetime | ○ | 自動 | 作成日時 |
| updated_at | DateTimeField | datetime | ○ | 自動 | 更新日時 |

### 9.2 並び順

`study_date` 降順、同日の場合 `id` 降順。

### 9.3 削除ルール

LearningGoal削除時はCASCADE。

## 10. リレーション

```text
User (0..1) ──< LearningGoal >── Category
                    |
                    | 1:N
                    v
                 Roadmap
                    |
                    | 1:N
                    v
              LearningTask

LearningGoal 1 ──< Reflection
```

| 親 | 子 | 関係 | FK | on_delete |
|---|---|---|---|---|
| User | LearningGoal | 1:N（LearningGoal側はNULL可） | `user_id` | CASCADE |
| Category | LearningGoal | 1:N | `category_id` | PROTECT |
| LearningGoal | Roadmap | 1:N | `learning_goal_id` | CASCADE |
| Roadmap | LearningTask | 1:N | `roadmap_id` | CASCADE |
| LearningGoal | Reflection | 1:N | `learning_goal_id` | CASCADE |

## 11. 削除影響

| 削除対象 | 結果 |
|---|---|
| Category | 学習目標から参照中の場合は削除不可（PROTECT） |
| LearningGoal | Roadmap、Roadmap配下LearningTask、Reflectionを連鎖削除 |
| Roadmap | 配下LearningTaskを連鎖削除 |
| LearningTask | 対象タスクのみ削除 |
| Reflection | 対象振り返りのみ削除 |
| User | 紐づくLearningGoalとその配下データを連鎖削除 |

## 12. Model/Formレベルの主要制約

| 対象 | 制約 |
|---|---|
| Category.name | 最大100文字、重複不可 |
| LearningGoal.title | 最大200文字、必須 |
| LearningGoal.target_date | 開始日がある場合、開始日以降（GoalForm） |
| Roadmap.title | 最大200文字、必須 |
| Roadmap.sort_order | 正の整数、Formでは1以上 |
| LearningTask.title | 最大200文字、必須 |
| LearningTask.material_url | 最大500文字、URL形式 |
| TaskForm.goal / roadmap | 選択したロードマップが選択した学習目標に属すること |
| Reflection.study_time | 非負整数、NULL可 |
| Reflection.learned | 必須 |

## 13. インデックス

明示的な `Meta.indexes` は現行Modelでは定義していない。ForeignKeyにはDjango/DBにより通常インデックスが作成される。検索頻度やデータ量が増加した場合、次の項目への追加インデックスを検討する。

- LearningGoal.status
- LearningGoal.created_at
- LearningTask.status
- LearningTask.priority
- LearningTask.due_date
- Reflection.study_date

ただし現行実装との一致を優先し、本設計段階では追加インデックスを実装済みとは扱わない。

## 14. トランザクション・整合性上の注意

- ロードマップの上下移動では2レコードの `sort_order` を順に更新する。現行コードでは明示的なDBトランザクションは使用していない。
- 進捗率は保存値ではないため、タスク状態変更後の値不整合は発生しにくい。表示時点のタスクデータから再計算する。
- TaskFormでは画面上のJavaScriptだけに依存せず、サーバー側でも学習目標とロードマップの整合性を検証する。
