# 学習ロードマップ・スキル成長管理アプリ 詳細設計書

## 1. 目的

本設計書では、各機能の具体的な処理内容を整理する。  
入力チェック、DB操作、画面遷移、エラー処理を明確にし、実装時の手戻りを減らすことを目的とする。

---

## 2. 学習目標登録処理

### 2.1 処理概要

ユーザーが入力した学習目標をDBに登録する。

### 2.2 処理の流れ

1. 学習目標登録画面を表示する
2. ユーザーが必要項目を入力する
3. 登録ボタンを押下する
4. 入力内容をチェックする
5. エラーがある場合は登録画面にエラーメッセージを表示する
6. エラーがない場合はlearning_goalsテーブルに登録する
7. 登録完了後、学習目標一覧画面へ遷移する

### 2.3 入力チェック

| 項目 | チェック内容 |
|---|---|
| タイトル | 必須 |
| カテゴリ | 必須 |
| 開始日 | 日付形式 |
| 目標期限 | 日付形式 |
| ステータス | 指定値のみ許可 |

### 2.4 DB操作

| 操作 | 対象テーブル | 内容 |
|---|---|---|
| INSERT | learning_goals | 入力された学習目標を登録する |

### 2.5 正常終了時

- 学習目標一覧画面へ遷移する
- 登録完了メッセージを表示する

### 2.6 異常終了時

- 登録画面に戻る
- 入力エラーメッセージを表示する
- DB登録失敗時はエラーメッセージを表示する

---

## 3. 学習目標更新処理

### 3.1 処理概要

登録済みの学習目標を編集する。

### 3.2 処理の流れ

1. 編集対象の学習目標IDを受け取る
2. learning_goalsテーブルから対象データを取得する
3. 編集画面に既存データを表示する
4. ユーザーが内容を変更する
5. 更新ボタンを押下する
6. 入力内容をチェックする
7. 問題がなければDBを更新する
8. 更新後、学習目標詳細画面へ遷移する

### 3.3 DB操作

| 操作 | 対象テーブル | 内容 |
|---|---|---|
| SELECT | learning_goals | 編集対象のデータを取得する |
| UPDATE | learning_goals | 入力内容でデータを更新する |

### 3.4 異常終了時

- 対象データが存在しない場合はエラーメッセージを表示する
- 入力内容が不正な場合は編集画面にエラーを表示する

---

## 4. 学習目標削除処理

### 4.1 処理概要

登録済みの学習目標を削除する。

### 4.2 処理の流れ

1. 削除対象の学習目標IDを受け取る
2. learning_goalsテーブルから対象データを取得する
3. 削除確認画面を表示する
4. ユーザーが削除を確定する
5. DBから対象データを削除する
6. 学習目標一覧画面へ遷移する

### 4.3 DB操作

| 操作 | 対象テーブル | 内容 |
|---|---|---|
| SELECT | learning_goals | 削除対象のデータを取得する |
| DELETE | learning_goals | 対象データを削除する |

### 4.4 注意点

- 紐づくロードマップ、タスク、振り返りも削除対象となる
- 誤削除防止のため、削除確認画面を表示する

| ステータス | 指定値のみ許可 |

|---|---|---|

## 8. タスク完了処理

### 8.1 処理概要

学習タスクのステータスを完了に変更する。

### 8.2 処理の流れ

1. タスク一覧画面または学習目標詳細画面を表示する
2. 対象タスクの完了ボタンを押下する
3. learning_tasksテーブルのstatusをcompletedに更新する
4. 関連する学習目標の進捗率を再計算する
5. 画面に更新後の進捗率を表示する

### 8.3 DB操作

| 操作 | 対象テーブル | 内容 |
|---|---|---|
| UPDATE | learning_tasks | statusをcompletedに更新する |
| SELECT | learning_tasks | 進捗率計算用にタスク件数を取得する |

---

## 9. 進捗率算出処理

### 9.1 処理概要

学習目標に紐づくタスクの完了状況をもとに進捗率を計算する。

### 9.2 計算方法

進捗率 = 完了タスク数 / 全タスク数 × 100

### 9.3 処理の流れ

1. 対象の学習目標に紐づくロードマップを取得する
2. ロードマップに紐づくタスクを取得する
3. 全タスク数を集計する
4. 完了タスク数を集計する
5. 進捗率を計算する
6. 画面に表示する

### 9.4 考慮事項

* タスクが0件の場合は進捗率を0%とする
* 小数点は四捨五入または切り捨てとする
* 完了タスクのみを進捗率の対象とする

## 11. 検索・絞り込み処理

### 11.1 処理概要

学習目標やタスクを条件指定して検索する。

### 11.2 検索条件

| 条件    | 対象            |
| ----- | ------------- |
| キーワード | タイトル、メモ、学んだこと |

## 12. ダッシュボード表示処理

### 12.1 処理概要

学習状況の概要をトップ画面に表示する。

### 12.2 表示データ

| 表示項目       | 取得元                                        |
| ---------- | ------------------------------------------ |
| 学習中の目標数    | learning_goals                             |
| 完了済み目標数    | learning_goals                             |
| 未完了タスク数    | learning_tasks                             |
| 期限が近いタスク   | learning_tasks                             |
| 今月の学習時間    | reflections                                |
| 最近の振り返り    | reflections                                |
| 学習目標ごとの進捗率 | learning_goals / roadmaps / learning_tasks |

### 12.3 処理の流れ

1. ダッシュボード画面へアクセスする
2. 学習目標、タスク、振り返り情報をDBから取得する
3. 集計処理を行う
4. ダッシュボード画面に表示する

---

## 13. 共通エラー処理

### 13.1 入力エラー

入力内容に不備がある場合、画面上にエラーメッセージを表示する。

例：

* タイトルを入力してください
* 日付の形式が正しくありません
* 指定された値が不正です

### 13.2 データ未存在エラー

指定されたIDのデータが存在しない場合、エラーメッセージを表示する。

例：

* 対象のデータが見つかりません

### 13.3 DBエラー

DB登録・更新・削除に失敗した場合、エラーメッセージを表示する。

例：

* 登録に失敗しました
* 更新に失敗しました
* 削除に失敗しました
